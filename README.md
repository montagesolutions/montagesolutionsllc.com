## Updating the Site

All content is in `index.html`. Search for the section you want to update and edit the text directly.

**Things to update when ready:**
- Replace `YOUR_FORM_ID` in the contact form action with your Formspree ID
- Add EIN once received
- Remove "(Certification Pending)" from WOSB once certified
- Update SAM.gov status once registered
- Add CAGE Code and UEI once available

## Publishing Changes

1. Edit `index.html`
2. Commit the change in GitHub
3. GitHub Pages auto-publishes within ~60 seconds
